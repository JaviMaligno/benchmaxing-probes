Para hallar el valor de $a^2 + b^2$, resolvemos el problema paso a paso:

1. **Altura del trapecio:**
   Dado que un círculo de radio $r = 5$ está inscrito en el trapecio y es tangente a sus cuatro lados, la altura $h$ del trapecio es igual al diámetro del círculo:
   $$h = 2r = 2(5) = 10$$

2. **Suma de las bases ($a + b$):**
   El área $A$ de un trapecio con bases paralelas $a$ y $b$ y altura $h$ viene dada por la fórmula:
   $$A = \frac{a + b}{2} \cdot h$$
   Sustituyendo $A = 160$ y $h = 10$:
   $$160 = \frac{a + b}{2} \cdot 10 \implies a + b = \frac{160}{5} = 32$$

3. **Producto de las bases ($ab$):**
   Por el teorema de Pitot, en todo cuadrilátero circunscrito a una circunferencia, las sumas de los lados opuestos son iguales. Si llamamos $c$ a la longitud de cada uno de los dos lados no paralelos (iguales por ser un trapecio isósceles), tenemos:
   $$a + b = 2c \implies c = \frac{a + b}{2}$$
   Al trazar las alturas desde los extremos de la base menor hasta la base mayor, se forman dos triángulos rectángulos congruentes de hipotenusa $c$, cateto vertical $h$ y cateto horizontal $\frac{|a - b|}{2}$. Por el teorema de Pitágoras:
   $$c^2 = h^2 + \left(\frac{a - b}{2}\right)^2$$
   Sustituyendo $c = \frac{a + b}{2}$:
   $$\left(\frac{a + b}{2}\right)^2 - \left(\frac{a - b}{2}\right)^2 = h^2 \implies ab = h^2$$
   Como $h = 10$, obtenemos:
   $$ab = 10^2 = 100$$

4. **Cálculo de $a^2 + b^2$:**
   Utilizando la identidad algebraica $a^2 + b^2 = (a + b)^2 - 2ab$:
   $$a^2 + b^2 = 32^2 - 2(100) = 1024 - 200 = 824$$

\boxed{824}
