Sea $r=5$ el radio del círculo inscrito.

**Paso 1: Altura del trapecio.** Como el círculo es tangente a ambas bases paralelas, la altura del trapecio es el diámetro:
$$h = 2r = 10.$$

**Paso 2: Suma de las bases.** El área de un trapecio es $\frac{a+b}{2}\cdot h$, así que
$$160 = \frac{a+b}{2}\cdot 10 = 5(a+b) \implies a+b = 32.$$

**Paso 3: Longitud del lado lateral.** En un cuadrilátero tangencial, las sumas de lados opuestos son iguales. Si $c$ es la longitud de cada lado no paralelo (son iguales por ser isósceles):
$$a + b = 2c \implies c = 16.$$

**Paso 4: Diferencia de las bases.** Al bajar la altura desde un extremo de la base menor, se forma un triángulo rectángulo con hipotenusa $c$, cateto vertical $h=10$ y cateto horizontal $\frac{a-b}{2}$:
$$c^2 = h^2 + \left(\frac{a-b}{2}\right)^2$$
$$256 = 100 + \frac{(a-b)^2}{4} \implies \frac{(a-b)^2}{4} = 156 \implies (a-b)^2 = 624.$$

**Paso 5: Calcular $a^2+b^2$.** Usando la identidad
$$a^2 + b^2 = \frac{(a+b)^2 + (a-b)^2}{2} = \frac{32^2 + 624}{2} = \frac{1024 + 624}{2} = \frac{1648}{2} = 824.$$
