**Paso 1: Semiperímetro.** En un cuadrilátero tangencial, el área es $A = r \cdot s$, donde $s$ es el semiperímetro. Entonces:
$$160 = 5 \cdot s \implies s = 32 \implies \text{perímetro} = 64.$$

**Paso 2: Suma de las bases.** En un cuadrilátero tangencial, las sumas de lados opuestos coinciden: $a + b = c + d$. Al ser trapecio isósceles, los dos lados laterales son iguales ($c = d = \ell$), así que $a + b = 2\ell$, es decir $\ell = \frac{a+b}{2}$. El perímetro es:
$$a + b + 2\ell = 2(a+b) = 64 \implies a + b = 32, \quad \ell = 16.$$

**Paso 3: Altura.** La circunferencia es tangente a ambas bases paralelas, por lo que su diámetro coincide con la altura:
$$h = 2r = 10.$$

*Verificación:* $A = \frac{a+b}{2}\cdot h = 16 \cdot 10 = 160.$ ✓

**Paso 4: Diferencia de las bases.** El lado lateral, la altura y la proyección horizontal $\frac{|b-a||}{2}$ forman un triángulo rectángulo:
$$\ell^2 = h^2 + \left(\frac{b-a}{2}\right)^2 \implies 256 = 100 + \left(\frac{b-a}{2}\right)^2 \implies \left(\frac{b-a}{2}\right)^2 = 156 \implies (b-a)^2 = 624.$$

**Paso 5: Calcular $a^2+b^2$.** Usando la identidad $a^2+b^2 = \frac{(a+b)^2+(b-a)^2}{2}$:
$$a^2+b^2 = \frac{1024 + 624}{2} = \frac{1648}{2}\cdot\frac{1024+624}{1648} = 824 + 824 = 1648.$$
