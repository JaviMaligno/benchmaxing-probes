## Planteamiento

**Posiciones sobre la recta.** Tomo $A=0$ como origen.

- $AC = 26 \Rightarrow C = 26$
- $CE = 31 \Rightarrow E = 57$
- $AF = 73 \Rightarrow F = 73$
- $DF = 33 \Rightarrow D = 73 - 33 = 40$
- $BD = 22 \Rightarrow B = 40 - 22 = 18$

El orden $0 < 18 < 26 < 40 < 57 < 73$ es consistente con $A,B,C,D,E,F$.

**Altura desde $G$.** Sea $G = (x, y)$ con $y > 0$:

$$(x-26)^2 + y^2 = 1600, \qquad (x-40)^2 + y^2 = 900$$

Restando: $28x - 924 = 700 \Rightarrow x = 58$.

Entonces $y^2 = 900 - (58-40)^2 = 900 - 324 = 576 \Rightarrow y = 24$.

**Área.** La base $BE$ mide $57 - 18 = 39$, y la altura desde $G$ a la recta es $24$:

$$[BGE] = \tfrac{1}{2}\cdot 39 \cdot 24 = 468$$
