## Planteamiento

**Altura del trapecio.** Como el círculo es tangente a ambos lados paralelos, la distancia entre ellos es un diámetro:
$$h = 2r = 10$$

**Suma de las bases.** Del área:
$$160 = \frac{a+b}{2}\cdot 10 \quad\Longrightarrow\quad a+b = 32$$

**Longitud de los lados oblicuos.** En un polígono circunscribible, las sumas de lados opuestos son iguales (teorema de Pitot). Siendo isósceles con lados iguales $c$:
$$a + b = 2c \quad\Longrightarrow\quad c = 16$$

**Relación entre bases.** Por Pitágoras en el triángulo rectángulo formado por el lado oblicuo, la altura y la proyección horizontal $\frac{a-b}{2}$:
$$c^2 = h^2 + \left(\frac{a-b}{2}\right)^2$$
$$256 = 100 + \left(\frac{a-b}{2}\right)^2 \quad\Longrightarrow\quad (a-b)^2 = 624$$

(Nota de consistencia: al ser $c=\frac{a+b}{2}$, resulta $\left(\frac{a+b}{2}\right)^2-\left(\frac{a-b}{2}\right)^2 = ab = h^2 = 100$, es decir $ab=100$, compatible con $a+b=32$ y discriminante $1024-400=624>0$, luego $a\neq b$ como se pide.)

**Resultado.**
$$a^2+b^2 = \frac{(a+b)^2 + (a-b)^2}{2} = \frac{1024 + 624}{2} = 824$$

O bien, directamente: $a^2+b^2 = (a+b)^2 - 2ab = 1024 - 200 = 824$.
