# aime25-11 variant

A function $g$ is defined piecewise by
\[g(x) = \begin{cases} x & \text{if } -1 \le x < 1 \\ 2 - x & \text{if } 1 \le x < 3\end{cases}\]
and is extended to all real numbers by $g(x + 4) = g(x)$, so its graph is a periodic zigzag of period $4$ oscillating between $-1$ and $1$.

The parabola $x = 66y^2$ meets the graph of $y = g(x)$ in finitely many points. The sum of the $y$-coordinates of all these intersection points can be written as $\tfrac{a + b\sqrt{c}}{d}$, where $a, b, c, d$ are positive integers, $\gcd(a, b, d) = 1$, and $c$ is not divisible by the square of any prime. Find $a + b + c + d$.

**Answer:** 835  (sum $= \tfrac{1 + 5\sqrt{697}}{132}$, 67 intersection points)
