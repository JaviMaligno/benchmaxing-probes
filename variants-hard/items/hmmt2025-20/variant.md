# hmmt2025-20 — variant

A circular track is divided into $36$ arcs, each of length $1$. Initially there are $12$ snakes, each of length $1$, placed on every third arc. Every second, each snake independently slides either one arc clockwise or one arc counterclockwise, each with probability $\frac{1}{2}$. Whenever two snakes touch, they fuse into a single snake occupying all the arcs of both, and the fused snake thereafter moves as one snake. Compute the expected number of seconds until only one snake remains.

**Answer:** $\frac{286}{3}$
