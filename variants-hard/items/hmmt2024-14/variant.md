# hmmt2024-14 variant

A beetle sits on the $3 \times 20$ lattice of points $(i, j)$ for all $1 \leq i \leq 3$ and $1 \leq j \leq 20$. It wants to visit every point in the lattice exactly once. In a move, the beetle can move to a point in the lattice exactly one unit away. Given that the beetle starts at $(2,1)$, compute the number of possible paths the beetle can take.

**Answer:** 1024

(Verified by brute-force DFS in solve.py; the same code gives 4096 for the original 3 x 24 lattice.)
