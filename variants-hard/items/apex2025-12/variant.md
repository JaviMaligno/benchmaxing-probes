# apex2025-12 variant

Consider a $2116 \times 2116$ board of unit cells. Theo wants to place some rectangular tiles on the board, not necessarily all of the same size, so that every side of every tile lies along a grid line and no unit cell is covered by more than one tile.

Find the minimum number of tiles Theo must place so that every row and every column of the board contains exactly one unit cell that is not covered by any tile.

**Answer:** 2205  ($= n + 2\sqrt{n} - 3$ with $n = 2116 = 46^2$)
