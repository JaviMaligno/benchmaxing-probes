# apex2025-08 variant

Bruno sketches a $5$ by $6$ rectangle. In how many ways can he completely tile this rectangle with L-shaped triominoes (each forming a $2\times 2$ square missing one corner) and paint each triomino red, green, or blue, so that any two neighboring triominoes receive different colors? (Two triominoes neighbor if they share a positive amount of perimeter.)

**Answer:** 3120

(Verified by brute force in solve.py: 72 tilings of the 5x6 rectangle; the same code gives 1164 for the original 4x6.)
