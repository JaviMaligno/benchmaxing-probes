# hmmt2024-17 variant

A hallway is a grid of cells with $2$ rows that extends infinitely to the right (it has a leftmost column but no rightmost one). Between any two edge-adjacent cells there is a door. Each door between two cells in the same row is locked with probability $\frac{1}{2}$, and each door between the two cells of the same column is locked with probability $\frac{1}{4}$, all independently. Mira starts in the top-left corner cell. She can move between two adjacent cells only if the door between them is unlocked. Compute the expected number of cells that Mira can reach (including her starting cell).

**Answer:** $\dfrac{92}{15}$
