# cmimc2025-40 variant

In a $6 \times 8$ grid of squares (6 rows, 8 columns), each square is painted either red or blue. A beetle starts on some red square and crawls parallel to the sides of the grid. Whenever it is on a red square it may (but need not) turn $90^{\circ}$ left or right; on a blue square it must keep crawling in the same direction.

A painting of the grid is called *safe* if the beetle can never return to its starting square. How many safe paintings are *maximal*, meaning that repainting any blue square red produces a painting that is not safe?

**Answer:** $6^{7}\cdot 8^{5} = 9172942848$
