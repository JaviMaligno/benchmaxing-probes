# hmmt2025-05 variant

Let $\mathcal{T}$ be the set of all nonconstant monic polynomials $F$ with integer coefficients such that $F(\sqrt{5}+\sqrt{3}) = F(\sqrt{5}-\sqrt{3})$. If $R$ is an element of $\mathcal{T}$ of minimal degree, compute the only possible value of $R(6)-R(1)$.

**Answer:** 125

(Minimal elements: $R(x) = x^3 - 18x + c$, $c \in \mathbb{Z}$.)
