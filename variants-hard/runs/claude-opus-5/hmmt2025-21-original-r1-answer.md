## Planteamiento

Como $BC = BE + EF + FC = 14 + 15 + 16 = 45$, el triángulo $ABC$ es equilátero de lado $45$, y $DEF$ es equilátero de lado $EF = 15$.

**Coordenadas.** Tomo $B = (0,0)$ y $C = (45,0)$:

- $A = \left(\tfrac{45}{2},\ \tfrac{45\sqrt3}{2}\right)$
- $E = (14, 0)$, $F = (29, 0)$
- Como $D$ está dentro de $\triangle ABC$, queda del mismo lado que $A$:
$$D = \left(\tfrac{14+29}{2},\ \tfrac{15\sqrt3}{2}\right) = \left(\tfrac{43}{2},\ \tfrac{15\sqrt3}{2}\right)$$

**Distancia.**
$$\Delta x = \tfrac{45}{2} - \tfrac{43}{2} = 1, \qquad \Delta y = \tfrac{45\sqrt3}{2} - \tfrac{15\sqrt3}{2} = 15\sqrt3$$

$$AD^2 = 1^2 + (15\sqrt3)^2 = 1 + 675 = 676$$

$$AD = 26$$
