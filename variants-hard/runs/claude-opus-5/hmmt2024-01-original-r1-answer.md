## Planteamiento

El polinomio $x^2 + rx + s$ tiene raíces $s$ y $t$. Por las fórmulas de Vieta:

- Suma: $s + t = -r$
- Producto: $s \cdot t = s$

Como $s \neq 0$, de $st = s$ se obtiene $t = 1$.

Entonces $s + 1 = -r$, es decir $r = -(s+1)$.

## Usando el segundo polinomio

El polinomio $x^2 + tx + r$ tiene a $5$ como raíz, y $t = 1$:

$$25 + 5(1) + r = 0 \implies r = -30$$

Por tanto $-(s+1) = -30$, de donde $s = 29$.

## Verificación

Con $r = -30$, $s = 29$, $t = 1$: el polinomio $x^2 - 30x + 29 = (x-1)(x-29)$ tiene raíces $29 = s$ y $1 = t$. ✓
El polinomio $x^2 + x - 30$ evaluado en $5$ da $25 + 5 - 30 = 0$. ✓
Los tres valores son no nulos. ✓
