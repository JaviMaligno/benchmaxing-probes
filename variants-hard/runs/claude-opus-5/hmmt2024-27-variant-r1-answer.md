## Planteamiento

El triángulo $PRS$ es el triángulo órtico de $XYZ$.

**1) Semejanza en el vértice $X$.**
Como $XR = XY\cos X$ y $XS = XZ\cos X$, el triángulo $XSR$ es semejante a $XYZ$ con razón $\cos X$. Por tanto la altura desde $X$ en $XSR$ es la altura desde $X$ en $XYZ$ multiplicada por $\cos X$:

$$XT = XP\cos X \quad\Longrightarrow\quad 15 = 20\cos X \quad\Longrightarrow\quad \cos X = \tfrac34,\qquad \sin X = \tfrac{\sqrt7}{4}.$$

**2) Lados del triángulo órtico.**
Con la notación $x=YZ$, $y=ZX$, $z=XY$:

$$RS = x\cos X,\qquad PS = y\cos Y,\qquad PR = z\cos Z.$$

Luego, con $x=2R_c\sin X$, etc.:

$$RS+PS+PR = R_c(\sin 2X+\sin 2Y+\sin 2Z) = 4R_c\sin X\sin Y\sin Z = \frac{2[XYZ]}{R_c},$$

usando $[XYZ]=2R_c^2\sin X\sin Y\sin Z$.

**3) Datos numéricos.**

$$[XYZ] = \tfrac12\cdot YZ\cdot XP = \tfrac12\cdot 16\cdot 20 = 160,\qquad R_c = \frac{x}{2\sin X} = \frac{16}{2\cdot \frac{\sqrt7}{4}} = \frac{32}{\sqrt7}.$$

$$\text{Perímetro} = \frac{2\cdot 160}{32/\sqrt7} = \frac{320\sqrt7}{32} = 10\sqrt7.$$

(Comprobación: $RS = 16\cdot\tfrac34 = 12 < 10\sqrt7 \approx 26{,}46$, consistente.)

$$\boxed{10\sqrt{7}}$$
