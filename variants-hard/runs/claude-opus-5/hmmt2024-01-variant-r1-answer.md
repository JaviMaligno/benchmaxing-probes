## Razonamiento

**Paso 1.** Como $b$ y $c$ son las raíces de $x^2+ax+b$, por las fórmulas de Vieta:
- $b + c = -a$
- $b \cdot c = b$

**Paso 2.** De $bc = b$ con $b \neq 0$ se obtiene $c = 1$.

**Paso 3.** Como $7$ es raíz de $x^2+cx+a$:
$$49 + 7c + a = 0 \implies 49 + 7 + a = 0 \implies a = -56$$

**Paso 4.** De $b + c = -a$:
$$b + 1 = 56 \implies b = 55$$

**Verificación.** Con $a=-56$, $b=55$, $c=1$: el polinomio $x^2-56x+55$ tiene raíces $1$ y $55$, es decir $c$ y $b$. ✓ El polinomio $x^2+x-56=(x+8)(x-7)$ tiene a $7$ como raíz. ✓ Todos son no nulos. ✓
