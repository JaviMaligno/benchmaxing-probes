Para encontrar el valor de $b$, analicemos las condiciones dadas paso a paso:

1. **Primera condición:** El polinomio $x^2 + ax + b$ tiene a $b$ y $c$ como sus raíces.
   Por las fórmulas de Vieta para el polinomio cuadrático $x^2 + ax + b = 0$, la suma y el producto de sus raíces cumplen:
   $$b + c = -a$$
   $$b \cdot c = b$$

   Dado que $b$ es un número real distinto de cero ($b \neq 0$), podemos dividir ambos lados de la segunda ecuación entre $b$:
   $$c = 1$$

   Sustituyendo $c = 1$ en la ecuación de la suma de las raíces, obtenemos:
   $$b + 1 = -a \implies a = -b - 1$$

2. **Segunda condición:** El polinomio $x^2 + cx + a$ tiene a $7$ como raíz.
   Evaluando el polinomio en $x = 7$ e igualando a cero:
   $$7^2 + c(7) + a = 0$$
   $$49 + 7c + a = 0$$

   Sustituimos $c = 1$ en esta ecuación:
   $$49 + 7(1) + a = 0$$
   $$56 + a = 0 \implies a = -56$$

3. **Cálculo de $b$:**
   Usando la relación $a = -b - 1$ con $a = -56$:
   $$-56 = -b - 1$$
   $$b = 56 - 1 = 55$$
