## Solución

Coloco el centro de la circunferencia en el origen, con el trapecio simétrico respecto al eje y:

- $A = (-2, a)$, $B = (2, a)$ con $4 + a^2 = 25$, es decir $a^2 = 21$.
- $D = (-c, d)$, $C = (c, d)$ con $c^2 + d^2 = 25$.
- Como $D$ está entre $E$ y $C$ con $DE = 2$: $E = (-c-2, d)$.
- $M = \left(\dfrac{-c-4}{2}, \dfrac{a+d}{2}\right)$.

**Condición de que $M$ esté en la circunferencia:**

$$\left(\frac{c+4}{2}\right)^2 + \left(\frac{a+d}{2}\right)^2 = 25 \implies (c+4)^2 + (a+d)^2 = 100$$

Expandiendo y usando $c^2 + d^2 = 25$, $a^2 = 21$:

$$25 + 8c + 16 + 21 + 2ad = 100 \implies 8c + 2ad = 38$$

**Cálculo de $MD$:**

$$MD^2 = \left(c - \frac{c+4}{2}\right)^2 + \left(d - \frac{a+d}{2}\right)^2 = \frac{(c-4)^2 + (d-a)^2}{4}$$

$$= \frac{c^2 + d^2 + a^2 + 16 - 8c - 2ad}{4} = \frac{25 + 21 + 16 - 38}{4} = \frac{24}{4} = 6$$

Por lo tanto $MD = \sqrt{6}$.
