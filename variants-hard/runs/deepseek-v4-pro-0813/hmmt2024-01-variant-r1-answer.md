Vamos a resolverlo paso a paso.

**Paso 1: Relaciones de raíces para el primer polinomio.**

El polinomio \(x^2 + ax + b\) tiene raíces \(b\) y \(c\). Por las fórmulas de Vieta:

- Suma de raíces: \(b + c = -a\)
- Producto de raíces: \(bc = b\)

Como \(b\neq 0\), de \(bc = b\) obtenemos:

\[
c = 1
\]

Entonces \(b + 1 = -a\), es decir:

\[
a = -b - 1 \tag{1}
\]

**Paso 2: Segundo polinomio.**

El polinomio \(x^2 + cx + a\) tiene \(7\) como raíz. Como \(c = 1\), el polinomio es:

\[
x^2 + x + a
\]

Sustituyendo \(x = 7\):

\[
49 + 7 + a = 0
\]

\[
a = -56
\]

**Paso 3: Calcular \(b\).**

De la ecuación (1):

\[
-56 = -b - 1
\]

\[
b = 55
\]

Por lo tanto:

\[
\boxed{55}
\]
